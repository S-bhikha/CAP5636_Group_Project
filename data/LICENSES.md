## 1. TinyStories — CDLA-Sharing-1.0

### Declared license

- Hugging Face dataset card: **`cdla-sharing-1.0`**
- Full text: [https://cdla.dev/sharing-1-0/](https://cdla.dev/sharing-1-0/)
- SPDX: `CDLA-Sharing-1.0`

### What the data is

Synthetic short stories generated by GPT-3.5 / GPT-4 for the TinyStories paper. Cite the paper whenever we describe the corpus.

### What we are allowed to do (plain language)

Under CDLA-Sharing-1.0, recipients may **Use** the data (including computational analysis / training) and **Publish** the data, subject to share-alike and attribution conditions when redistributing **data** (not ordinary “Results”).

Key definitions from the license:

- **Use** includes accessing, copying, analyzing, and **Computational Use** (e.g. training a model).
- **Results** = outcomes of Computational Use that do **not** include more than a *de minimis* portion of the original Data (e.g. trained weights, loss curves, generated samples that are not large data extracts).
- **Publish** = making Data (or Enhanced Data) available to others outside your team/entity.

### Obligations when we redistribute **data**

If we **Publish** TinyStories data we received, or **Enhanced Data** (our modifications / additions packaged as data):

1. **Share-alike:** Publish it under **unmodified CDLA-Sharing-1.0** (include the agreement text, name, and/or a reliable link).
2. **Attribution:** Preserve credit / attribution to the Data Provider(s) (notices, metadata, identification, practical hyperlinks).
3. **Change notices:** If files are modified (Enhanced Data), carry **prominent notices** that we changed them.
4. **No extra restrictions** on use of the published data (including commercial use).

### What is *not* forced into CDLA-Sharing by the license text

Section 3.5: the agreement **imposes no obligations or restrictions on Use or Publication of Results**.

For this course project that means:

- Model checkpoints, metrics, paper figures, and ordinary generation samples are treated as **Results** of Computational Use, provided we are not shipping substantial raw TinyStories text as the product.
- **Do not** paste large chunks of the TinyStories corpus into the paper, slides, or public samples beyond short illustrative excerpts with citation.

### Repo policy (TinyStories)

| Action | Policy |
| --- | --- |
| Keep full `train.jsonl` / `validation.jsonl` in git | **No** — gitignored; rebuild via script |
| Share a copy of the raw dump with teammates outside git | OK for private course use; if **Published** more broadly, keep CDLA-Sharing terms + attribution |
| Publish a *filtered / reformatted* JSONL of TinyStories | Treat as Enhanced Data → CDLA-Sharing + change notice + attribution |
| Train B0 on TinyStories; release model code + small samples | Results path; still **cite** dataset + paper |

### Required citation / acknowledgment (TinyStories)

**In the paper (Methods or Data section), include something like:**

> We use the TinyStories dataset (Eldan & Li, 2023), available at Hugging Face as `roneneldan/TinyStories` under the Community Data License Agreement – Sharing, Version 1.0 (CDLA-Sharing-1.0). Stories are synthetically generated (GPT-3.5 / GPT-4).

**BibTeX-style reference (expand as needed):**

```text
Eldan, R., & Li, Y. (2023). TinyStories: How Small Can Language Models Be
and Still Speak Coherent English? arXiv:2305.07759.
Dataset: https://huggingface.co/datasets/roneneldan/TinyStories
License: CDLA-Sharing-1.0 (https://cdla.dev/sharing-1-0/)
```

**In the repo README / data docs:** link the HF card, CDLA-Sharing text, and paper (this file + `data/README.md`).

## 2. Wikipedia — CC BY-SA + GFDL

### Declared licenses

**Hugging Face dataset card** (`wikimedia/wikipedia`) states:

- [Creative Commons Attribution-ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/) (**CC BY-SA 3.0**)
- [GNU Free Documentation License](https://www.gnu.org/licenses/fdl-1.3.html) (**GFDL**)

**Wikimedia dumps legal page** ([dumps.wikimedia.org/legal.html](https://dumps.wikimedia.org/legal.html)) currently describes original textual content as dual-licensed under:

- [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- [GFDL](https://www.gnu.org/licenses/fdl-1.3.html)

Wikimedia [Terms of Use](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use) (content licensing) is the controlling project policy for live Wikipedia content; dump packaging may lag version numbering on third-party cards.

**Our practical stance:** treat Wikipedia article text as **Attribution-ShareAlike free content** under the Wikimedia dual-license regime, **give clear attribution**, link license deeds, and cite the dump / HF packaging we actually used (`20231101.simple` via `wikimedia/wikipedia`). Prefer linking **both** the HF licensing section and the dumps legal page so reviewers can see the source chain.

### What we use

- Config: **`20231101.simple`** (Simple English Wikipedia, Nov 2023 dump packaging)
- Fields retained locally: `id`, `url`, `title`, `text`
- Role: encyclopedic continued pretraining control (**B1** only — not Stage 1)

### CC BY-SA core obligations (plain language)

When you **share** or **adapt** licensed material (including substantial reuse of article text):

1. **Attribution (BY)** — give appropriate credit, provide a **license link**, and **indicate if changes were made**.
2. **ShareAlike (SA)** — if you remix, transform, or build upon the material *and redistribute that adapted material*, distribute your contributions under the **same** (or compatible) license.
3. **No additional legal terms** that restrict what the license allows.

**Attribution for Wikipedia text typically includes:**

- Credit to **Wikipedia / Wikimedia contributors** (authors are the community; individual article URLs are ideal when quoting specific pages)
- Title of the work (article title) when applicable
- Link to the source (article URL and/or dump / dataset)
- License name + link (CC BY-SA and note GFDL dual-licensing where relevant)
- Indication of changes (e.g. “text cleaned/stripped of references by the `wikimedia/wikipedia` dataset pipeline; further subsetted to Simple English config `20231101.simple` for this project”)

### GFDL note

GFDL is a copyleft documentation license that co-covers much historical Wikipedia text. For ML dump reuse, researchers usually satisfy community expectations primarily via **CC BY-SA attribution + ShareAlike awareness**, while acknowledging the **dual-license** statement on the dataset card and dumps legal page. We do **not** attempt to relicense Wikipedia text as something else.

### Training models on Wikipedia (project note)

Training a language model on Wikipedia text is common in research. **ShareAlike** is aimed at redistributed **adapted content**, not a simple claim that “all model weights must be CC BY-SA.” That said:

- Do **not** dump large verbatim Wikipedia passages into papers, demos, or SFT targets without attribution and license notice.
- If we **republish** a Wiki-derived text corpus (e.g. a filtered JSONL of articles), keep **CC BY-SA** (compatible dual-license awareness) + attribution + change notices.
- Generated stories in eval are **not** “Wikipedia articles,” but if a generation **quotes or closely paraphrases** a card-sourced fact that came from Wiki, prefer short excerpts and attribute in qualitative appendices when needed.

### Repo policy (Wikipedia)

| Action | Policy |
| --- | --- |
| Full `20231101_simple.jsonl` in git | **No** — gitignored; rebuild via script |
| Quote a short passage in the paper | OK with **article title, URL if known, CC BY-SA notice, “from Wikipedia”** |
| Redistribute our local Wiki JSONL publicly | **CC BY-SA** (+ dual GFDL acknowledgment) + attribution + note of processing changes |
| B1 CPT on Simple English Wiki | Allowed research use; **attribute in paper Methods** |

### Required citation / acknowledgment (Wikipedia)

**In the paper (Methods or Data section), include something like:**

> For the encyclopedic continued-pretraining baseline (B1), we use Simple English Wikipedia articles from the Wikimedia dump packaging `20231101.simple` via the Hugging Face dataset `wikimedia/wikipedia`. Wikipedia text is available under the Creative Commons Attribution-ShareAlike license and the GNU Free Documentation License; see the dataset card and [Wikimedia dumps legal information](https://dumps.wikimedia.org/legal.html). We attribute Wikipedia / Wikimedia contributors and do not claim ownership of article text.

**Citation block:**

```text
Wikimedia Foundation. Wikipedia dumps.
  https://dumps.wikimedia.org
Packaged dataset: https://huggingface.co/datasets/wikimedia/wikipedia
  (config: 20231101.simple)
Licensing: CC BY-SA (see dataset card / dumps.wikimedia.org/legal.html) and GFDL.
Terms of Use: https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use
```

**Optional BibTeX-style online reference (from the HF card):**

```bibtex
@online{wikidump,
  author = {{Wikimedia Foundation}},
  title  = {Wikimedia Downloads},
  url    = {https://dumps.wikimedia.org}
```
